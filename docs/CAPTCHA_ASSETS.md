Initial selection is random; a refresh excludes the last background tag. All active backgrounds are 600 × 360 and all generated puzzle strips are 110 × 360 (transparent vertical padding included).

For sequential challenges from the same resolved IP within two minutes, the server retains the previous target privately in Redis and requires a horizontal difference of at least 40 source pixels. Simultaneous requests from different tabs are not serialized. Tests check consecutive differences, allowed image tags, dimensions and successful real-engine matching.
