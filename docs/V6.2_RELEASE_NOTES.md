# Lyle Backend V6.2

- Added private, user-owned chat attachments with a Flyway migration, validation, storage metadata, expiry, and ordered message binding.
- Added authenticated upload, inline content, download, and draft-delete endpoints.
- Extended chat requests with `attachmentIds`, history messages with `attachments[]`, and Python requests with trusted storage references.
- Added turn replay protection and retained the legacy image-URL compatibility path.
- Added attachment service tests and controller slice coverage.
